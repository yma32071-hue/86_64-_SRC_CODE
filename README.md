# 86_64-_SRC_CODE
This is my new x86_64 emulator project made from c++ to be an alternative to Bochs!
# How to Compile (HTC)
## Linux
run ``` sudo apt install cmake && cmake build -ninja ```
## Windows
download and open the ``` x86++Installler.exe ```
or download the portable ``` x86++portable.zip ``` and unzip it with any tool you like.
